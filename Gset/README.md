# G-set comparison workflow

The active repository compares two workflows using 448 replicas:

- `Gset_OIM.py` loads an archived oscillator checkpoint from
  `raw_data/Gset/checkpoint_G*.txt.npz`, reads the replica count from
  `replica_states.shape[0]`, and applies the documented short MH refinement.
  The supplied checkpoints each contain 448 replicas.
- `Gset_MH.py` runs the pure-MH comparison directly from a `G*.txt` graph
  with a default population of 448 replicas.

The oscillator stage that originally generated the checkpoint files is not
part of the active repository. The checkpoints are fixed archived scientific
inputs and are not regenerated by these scripts.

Select an instance by editing `TARGET_NPZ` in `Gset_OIM.py` or `TARGET_TXT`
in `Gset_MH.py`. From the repository root, run:

```bash
cd raw_data/Gset
python ../../Gset/Gset_OIM.py
python ../../Gset/Gset_MH.py
```

Both programs are CPU-intensive and print their Max-Cut summaries to standard
output. They do not write a separate results archive.
