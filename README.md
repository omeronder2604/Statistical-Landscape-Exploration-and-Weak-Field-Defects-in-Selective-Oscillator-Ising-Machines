# Statistical Landscape Exploration and Weak-Field Defects in Selective Oscillator Ising Machines

Research code, manuscript source, figures, and retained data accompanying the work by **Ömer Önder and Aydın Cem Keser**. [arXiv:2609.14550](https://arxiv.org/abs/2609.14550) is the public **v1 preprint**. [`paper/OIMp_v4.tex`](paper/OIMp_v4.tex) is the **current journal manuscript source prepared for submission**; it is a later manuscript version.

OIM+ combines oscillator evolution with energy-based selection and repopulation. DH-OIM+ applies a short Metropolis–Hastings (MH) refinement; pure MH is an independent comparison. The main simulations use Sherrington–Kirkpatrick (SK) matrices. Nine G-set Max-Cut graphs and historical oscillator checkpoints are also retained. See [Gset/README.md](Gset/README.md) for the limits of the G-set record.

## Installation

The minimum **observed Python imports** are `numpy`, `scipy`, `numba`, `matplotlib`, and `mpi4py`, as listed without invented version pins in `requirements.txt`. MPI programs additionally require a compatible **system MPI** implementation. For an environment with MPI installed, run these commands from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Use the activation command appropriate to your shell or platform. The non-MPI analysis scripts use the first four packages; `mpi4py` is imported by the MPI drivers. Exact historical Python, package, MPI, compiler, and BLAS versions were not retained. The Slurm files are TRUBA-oriented examples with site-specific modules, partition, resources, and an environment name; adapt them before cluster use. Fixed seeds do not imply bitwise agreement across different numerical environments.

## Commands

All examples below **start at the repository root**. Most legacy scripts use source-level settings and look for input basenames in the current working directory; inspect their constants before a new run. Analysis commands write figures in their working directory and may be expensive.

```bash
# No input archive; writes the schedule PDF in schedule/.
(cd schedule && python Schedule.py)

# Saved 30-realization SK archives; output figures go to raw_data/.
(cd raw_data && python "../OIM/OIM_Averaged_P(q).py")
(cd raw_data && python "../MH/Pure_MH_Averaged_P(q).py")
(cd raw_data && python "../OIM/AF_OIM_Averaged_P(q).py")
(cd raw_data && python "../MH/AF_Pure_MH_Averaged_P(q).py")

# Representative J0=0 archive; both scripts regenerate a pure-MH comparison.
(cd raw_data && python ../energy_prog/energy_prog.py)
(cd raw_data && python ../dendrogram/dendograms.py)

# Local-field and correction-kernel analysis of the saved J0=0 OIM archive.
python PP/local_field_analysis.py \
  raw_data/AllToAll_Hybrid_EA_SeedAvg_AveragedData.npz --outdir PP/outputs
```

The representative pure-MH numerical result is **regenerated by code**, not retained as a numerical output archive. `energy_prog.py` and `dendograms.py` therefore take longer than simple plotting. Production-scale SK programs can be invoked from the repository root as follows; they are separate new executions, not reads of the archived results:

```bash
(cd HPC/Single_OIM && mpirun -np 8 python single_EA.py)
(cd HPC/Seed_Avg_OIM && mpirun -np 8 python avg.py)
(cd HPC/Seed_Avg_OIM/AF && mpirun -np 8 python AF_avg.py)
(cd HPC/Seed_Avg_MH && mpirun -np 8 python MH.py)
(cd HPC/Seed_Avg_MH/AF && mpirun -np 8 python AF_MH.py)
```

For G-set local programs, set `TARGET_NPZ` in `Gset_OIM.py` and `TARGET_TXT` in `Gset_MH.py` to the same desired instance before running:

```bash
(cd raw_data/Gset && python ../../Gset/Gset_OIM.py)
(cd raw_data/Gset && python ../../Gset/Gset_MH.py)
```

These programs print cut summaries and do not save a final-result archive. The current MPI oscillator program has a different scope from the manuscript's selective G-set history; its separate execution instructions and overwrite precautions are in [Gset/README.md](Gset/README.md).

## Retained SK data and figure inputs

The `J0=0` and `J0=-4` branches use separate archives. Each 30-realization archive contains 402 replicas per realization at `N=200`.

| Archive under `raw_data/` | Retained data and manuscript figures |
| --- | --- |
| `AllToAll_Hybrid_EA.npz` | One representative seed-52, `J0=0` OIM+/DH-OIM+ run, including spins and trajectory arrays; input to `Osc_energy_prog.pdf`, `MH_energy_prog.pdf`, and all three `Dendrogram_*.pdf` figures. The scripts regenerate the pure-MH comparison. |
| `AllToAll_Hybrid_EA_SeedAvg_AveragedData.npz` | `J0=0` OIM+/DH-OIM+ matrices, spins, energies, overlaps, and trajectory summaries; input to `Avg_Plot_2_Comparative_Overlap.pdf`, `Avg_Plot_3_Comparative_Energy.pdf`, `Main_LocalFields_Palmer_J0_0.pdf`, and `Main_Kemp_vs_Kfrz_J0_0.pdf`. |
| `AllToAll_PureMH_MPI_SeedAvg_AveragedData.npz` | `J0=0` pure-MH matrices, spins, energies, and overlaps; input to `Avg_Plot_PureMH_Overlap.pdf` and `Avg_Plot_PureMH_EnergyDist.pdf`. |
| `AF_AllToAll_Hybrid_EA_SeedAvg_AveragedData.npz` | `J0=-4` OIM+/DH-OIM+ data; input to `AF_Avg_Plot_2_Comparative_Overlap.pdf` and `AF_Avg_Plot_3_Comparative_Energy.pdf`. |
| `AF_AllToAll_PureMH_MPI_SeedAvg_AveragedData.npz` | `J0=-4` pure-MH data; input to `AF_Avg_Plot_PureMH_Overlap.pdf` and `AF_Avg_Plot_PureMH_EnergyDist.pdf`. |

`schedule/Schedule.py` supplies `OIM_Schedule.pdf` without an input archive. The figure basenames above refer to the retained files in `paper/Figures/`.

## Retained G-set data and limits

`raw_data/Gset/` contains graph texts `G1`, `G6`, `G11`, `G14`, `G15`, `G22`, `G23`, `G36`, and `G39` (each with `.txt`), and one matching `checkpoint_G*.txt.npz` per graph. Five graphs have 800 nodes and four have 2,000. Every checkpoint holds a graph matrix and **448 continuous-phase replicas**, before local MH refinement.

[`gset_reported_results.csv`](raw_data/Gset/gset_reported_results.csv) is a machine-readable **transcription of the nine rows reported in the current manuscript table**. It is **not a reconstruction of archived run output**. Underlying final refined and pure-MH configurations, per-replica cut arrays, and run logs were not retained. The original checkpoint-generating code revision and selection/repopulation history cannot be established from these files; the current G-set MPI search does not implement that selective history.

The SK archives likewise do **not** retain full oscillator phase or noise histories, RNG states, explicit child seeds, code hashes, or the exact original software environment. The five SK NPZs and nine G-set checkpoints are the retained numerical inputs; manuscript figure PDFs are in `paper/Figures/`.
